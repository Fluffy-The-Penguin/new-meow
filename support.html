Common fixes

Before you panic, check these.

Commands missing

Make sure the bot was invited with application command scope. Discord can also take time to propagate updates.

Bot not replying

Check talk channel settings and whether Meow Bot has View Channel and Send Messages permissions.

Game not starting

Some games require no other active channel-wide game, enough participants, or configured game channels.

Dashboard access

Admin dashboard access requires current Manage Server or Administrator permissions and the bot must still be in that server.
