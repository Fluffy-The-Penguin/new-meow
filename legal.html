Terms and privacy

Clear rules, simple privacy.

Meow Bot stores only the data needed for features like games, pets, economy, reminders, dashboard settings, and server configuration.

Terms

Use the bot respectfully.

Acceptable use

Do not abuse, spam, exploit, harass, or attempt to disrupt Meow Bot, Discord, or other communities.

Server responsibility

Server owners and admins are responsible for configuring channels, permissions, and feature access appropriately.

Availability

Features may change, degrade, or be unavailable during maintenance, provider outages, or Discord/API issues.

Enforcement

Abusive users or servers may be blocked from using the bot to protect the service and other communities.

Privacy

Data used for bot features.

Stored data

User IDs, server IDs, configured channel IDs, coins, XP, game stats, pet data, preferences, reminders, and dashboard sessions may be stored.

Why it is stored

The bot needs this data to run progression, games, moderation setup, reminders, dashboards, and personalization.

User controls

Use /mydata, reminder controls, and quest notification settings where available to manage participation.

Contact

Questions or data requests can go to thepenguinfluffy@gmail.com or the support server.
