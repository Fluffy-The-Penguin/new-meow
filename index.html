FAQ

Setup questions, answered fast.

Why are slash commands not appearing?

Discord can take time to propagate commands. Re-invite with application command scope or wait a little after updates.

How do I make the bot talk in one channel?

Use the talk channel setup command or admin dashboard so chat behavior stays contained to the channel you choose.

Does Meow Bot support private reminders?

Yes. Reminder DMs and daily quest completion notices can be toggled by users.

Can I control update posts?

Yes. Configure announcement and update channels, then use the owner tools for saved changelogs and announcements.
