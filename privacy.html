Privacy

Data used for bot features.

This privacy policy explains what Meow Bot may process, why that information is used, how it may be retained, and what rights users may have regarding their data.

Effective date

May 3, 2026

Summary

Meow Bot may process limited Discord-related data needed to provide features, maintain server settings, operate games, run dashboards, and protect service stability.

What may be processed

  • Discord user IDs, guild IDs, channel IDs, role IDs, and message IDs
  • Public profile details made available through Discord
  • Discord OAuth profile, guild list, permission flags, and temporary dashboard session data for dashboard access
  • Guild-specific settings configured by administrators
  • Optional server-only identity card details such as nickname, date of birth, age display, gender or pronouns, country, height, vibes, spirit animal, and selected friends
  • Command input, game interaction data, and message content used for supported gameplay or chat features
  • Progression data such as coins, XP, levels, streaks, quests, achievements, and inventory
  • Pet-related state such as egg ownership, pet lifecycle, mood, care timers, jobs, abilities, battles, pet image paths, and optional uploaded pet images
  • Movie-related state such as ratings, watched history, watchlists, overlap data, and poll participation
  • Anime and manga library state, imported public AniList IDs, watch/read status, and related recommendation state
  • Media delivery state such as used animal image URLs, cached lookup results, and external image source references
  • Feature requests, utility requests, bug reports, review status, and related update-delivery history
  • Reminder preferences, lottery entries, and guild event participation
  • Operational logs needed for debugging, moderation, abuse review, or security investigation

How it is used

  • To provide command responses and bot features
  • To store progression, game, pet, or guild configuration state
  • To manage channel-based systems such as talk channels, pet channels, logs channels, dashboards, and game-specific workflows
  • To send optional reminder DMs or public server notifications for configured features
  • To support AI replies, movie recommendations, anime and manga lookups, dictionary lookups, Wikipedia lookups, media-backed commands, and game prompts
  • To investigate misuse, fraud, spam, or abuse
  • To improve reliability, security, and service quality
  • To comply with legal obligations when required

Third-party services

Some Meow Bot features rely on external services such as Discord and Discord OAuth, hosting and deployment providers, configured AI providers such as Groq, Google Gemini, Hugging Face, or OpenRouter, TMDB for movie features, AniList for anime and manga features, dictionaryapi.dev and Datamuse for word support, Wikipedia and Wikimedia Commons for article and image lookups, PokeAPI for WTP game data, Reddit JSON feeds, TheCatAPI, Cataas, dog.ceo, random animal APIs, meme providers, Pexels, Wallhaven, NASA, trivia APIs, joke APIs, advice APIs, and related infrastructure needed to serve dashboards and the website update feed. Those providers may process request data needed to deliver those features.

Message content and feature scope

Meow Bot may read message content where necessary for active gameplay, AI chat features, talk-channel or mention replies, answer handling, counting, automatic reaction triggers, or other interactive systems that depend on user text input. Public ! text commands are retired in the current build.

Sharing and retention

Meow Bot does not sell personal data. Information may be shared with hosting or infrastructure providers only when necessary to operate the service or when disclosure is legally required. Data is retained only as long as reasonably necessary for functionality, moderation, safety, diagnostics, and legal compliance.

User rights and security

Depending on applicable law, users may request access, correction, deletion, restriction, or objection regarding their data. Reasonable safeguards are used to protect stored information, though no internet-based system can guarantee absolute security.

Deletion and reset requests

If you want stored data removed or reset, use /mydata where available or contact support and include the relevant server context, your Discord ID if needed, and the type of data or feature involved. Administrative reset tools may also exist for some server-managed states.

Server administrators

Server administrators are responsible for how they configure Meow Bot in their servers, including dashboard changes, channel setup, feature use, and whether the bot is made available to server members in a given context.

Contact

Questions, support requests, deletion requests, or privacy questions can go to thepenguinfluffy@gmail.com or the support server.
